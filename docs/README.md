# Documentazione di Trota OS

Trota OS è una distribuzione Linux desktop basata su **Ubuntu 24.04 LTS**,
sviluppata e pubblicata da **TestardStudios**. Questa è la documentazione
ufficiale del progetto; la stessa versione è installata offline nel sistema
(pacchetto `trota-docs`, apribile da *Benvenuto in Trota OS → Aiuto e supporto*).

| Documento | Contenuto |
|---|---|
| [Installazione](installation.md) | Requisiti hardware, creazione della chiavetta, installazione, primo avvio |
| [Architettura](architecture.md) | Scelte tecniche e registro delle decisioni (ADR) |
| [Generazione della ISO](building.md) | Procedura riproducibile per compilare pacchetti e immagine |
| [Test](testing.md) | Test automatici, test in macchina virtuale e risultati |
| [Risoluzione dei problemi](troubleshooting.md) | Problemi comuni e soluzioni prudenti |
| [Sicurezza](security.md) | Modello di sicurezza, aggiornamenti, privacy |
| [Privacy](privacy.md) | Quali dati vengono trattati (nessuna telemetria) |
| [Licenze](licensing.md) | Componenti, licenze, obblighi di distribuzione, marchi |
| [Identità visiva](brand.md) | Logo, palette, uso degli asset grafici |
| [Note di rilascio](release-notes.md) | Novità e problemi noti della versione 1.0 |
