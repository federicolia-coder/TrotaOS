Edizioni

Una base, quattro edizioni

Le quattro edizioni nascono dallo stesso repository e ricevono gli stessi aggiornamenti. Cambia solo quello che c'è sopra la base: chi gestisce un ufficio usa lo stesso sistema sui PC, sul server e sugli schermi della reception.

Le edizioni Server, Cloud e Kiosk sono immagini disco pronte: si scrivono su un disco o si importano in una piattaforma di virtualizzazione. Al primo avvio cloud-init allarga il disco, crea le chiavi SSH e configura rete e utente.

Server ed edge

Senza interfaccia grafica, con SSH solo a chiave, firewall attivo e container Podman anche senza root. Per server, mini PC e gateway.

  • 380 pacchetti
  • hardening del kernel di serie
$ podman run --rm -it alpine $ sudo ufw status Status: active

Cloud

Kernel per hardware virtuale e agente QEMU. L'accesso avviene con le chiavi SSH che la piattaforma passa a cloud-init.

  • qcow2 di circa 0,55 GB
  • EC2, Azure, GCE, OpenStack, Proxmox, NoCloud
$ cloud-init status status: done

Kiosk e signage

Una pagina web a tutto schermo su un sistema bloccato. Se il browser si chiude riparte; ogni notte si riavvia pulito.

  • Firefox in modalità kiosk
  • configurabile con cloud-init
# /etc/trota-kiosk.conf TROTA_KIOSK_URL=https://menu.bar.it

IoT ed edge

Dal sensore allo schermo

Un mini PC con Trota OS Server fa da gateway: riceve i dati dei sensori, li elabora sul posto anche senza internet e li manda al server centrale. Gli schermi con Trota OS Kiosk mostrano la dashboard. Tutto con lo stesso sistema, gli stessi aggiornamenti e la stessa configurazione cloud-init.

Sensori Gateway · Server Server centrale · Cloud Schermi · Kiosk

Container per ogni servizio

Broker MQTT, Node-RED, database e il tuo codice girano in container Podman separati, senza root. Si aggiornano uno alla volta senza toccare il sistema.

Cento dispositivi, una configurazione

Lo stesso file cloud-init imposta nome, chiavi SSH, rete e servizi su ogni gateway e su ogni schermo. Una chiavetta CIDATA basta anche senza cloud.

Fatto per stare acceso

Journal limitato a 500 MB per non riempire dischi piccoli, aggiornamenti di sicurezza automatici, console seriale per l'accesso senza schermo.

# sul gateway: broker MQTT e Node-RED $ podman run -d --name mqtt -p 1883:1883 docker.io/library/eclipse-mosquitto $ podman run -d --name flows -p 1880:1880 docker.io/nodered/node-red $ sudo ufw allow 1883/tcp && sudo ufw allow 1880/tcp

Hardware: PC x86 a 64 bit, come mini PC, PC industriali fanless e thin client, da 2 GB di RAM. Le schede ARM, come Raspberry Pi, non sono ancora supportate.

  1. Verifica il file

    Ogni file ha accanto il suo checksum SHA-256.

    $ sha256sum -c trota-os-1.0-amd64.iso.sha256 trota-os-1.0-amd64.iso: OK

  2. Prepara la chiavetta

    Usa balenaEtcher o GNOME Disks. Dal terminale, il comando cancella il disco indicato.

    $ sudo dd if=trota-os-1.0-amd64.iso \ of=/dev/sdX bs=4M conv=fsync

  3. Avvia e prova

    Avvia il computer dalla chiavetta: Trota OS parte senza installare nulla. L'icona sul desktop avvia l'installazione.

Domande

Domande frequenti

Quanto costa?

Per uso personale niente, su tutti i computer che vuoi. Per aziende, scuole ed enti TestardStudios prepara un'offerta con supporto, immagini personalizzate e uso del marchio: scrivi a sales@testardstudios.it.

Posso provarlo senza installarlo?

Sì. La ISO desktop parte dalla chiavetta in modalità live: il disco del computer non viene toccato finché non scegli di installare.

Si può usare per l'IoT?

Sì, su hardware x86 a 64 bit: l'edizione Server fa da gateway con broker MQTT, Node-RED e i tuoi servizi in container Podman; l'edizione Kiosk mostra le dashboard. Le schede ARM come Raspberry Pi non sono ancora supportate.

Come configuro tanti dispositivi uguali?

Con cloud-init: un file user-data con nome, chiavi SSH, rete e servizi, passato dalla piattaforma cloud o da una chiavetta con etichetta CIDATA. Lo stesso file vale per ogni gateway o schermo.

I programmi per Linux funzionano?

Sì. Trota OS è compatibile con i pacchetti .deb, i PPA e i repository pensati per Ubuntu 24.04 LTS. In più ci sono le app Flatpak di Flathub.

Fino a quando riceve aggiornamenti?

Gli aggiornamenti di sicurezza arrivano fino ad aprile 2029 e si installano da soli. Le nuove versioni di Trota OS escono come nuove immagini.

Perché non ci sono gli snap?

Per tenere il sistema leggero: Firefox è il pacchetto ufficiale di Mozilla e le altre applicazioni arrivano da Flathub. Chi vuole gli snap può riattivarli.

Serve un account o una connessione?

No. La rete serve solo per gli aggiornamenti e per installare nuove applicazioni.

Funziona in macchina virtuale?

Sì: tutte le edizioni sono provate in QEMU/KVM con firmware BIOS, UEFI e Secure Boot. L'edizione Cloud è fatta apposta per Proxmox, OpenStack e i cloud pubblici.
