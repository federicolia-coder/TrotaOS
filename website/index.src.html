Trota OS 1.0

Il sistema operativo leggero di TestardStudios. Lo stesso sistema per il portatile, il server, il cloud e lo schermo di un chiosco, con gli aggiornamenti di sicurezza che si installano da soli.

1.0 “Fario” · amd64 · BIOS e UEFI con Secure Boot

Desktop

GNOME su Wayland, tema scuro, Firefox, LibreOffice e gli strumenti per programmare. All'accesso il sistema usa circa 0,9 GB di memoria: niente indicizzatore dei file, niente negozio di app in background, niente notifiche promozionali.

Server, cloud e kiosk

Immagini disco pronte all'uso: si scrivono su un disco o si importano in una piattaforma di virtualizzazione. Al primo avvio cloud-init allarga il disco, crea le chiavi SSH e configura rete e utente.

Server ed edge

Senza interfaccia grafica, con SSH solo a chiave, firewall attivo e container Podman anche senza root. Per server, mini PC e gateway.

  • circa 270 MB di RAM in uso
  • 380 pacchetti
$ podman run --rm -it alpine $ sudo ufw status Status: active

Cloud

Kernel per hardware virtuale e agente QEMU. L'accesso avviene con le chiavi SSH che la piattaforma passa a cloud-init.

  • qcow2 di circa 0,55 GB
  • EC2, Azure, GCE, OpenStack, NoCloud
$ cloud-init status status: done

Kiosk e signage

Una pagina web a tutto schermo su un sistema bloccato. Se il browser si chiude riparte; ogni notte si riavvia pulito.

  • Firefox in modalità kiosk
  • configurabile con cloud-init
# /etc/trota-kiosk.conf TROTA_KIOSK_URL=https://menu.bar.it

Sicurezza e privacy

  • Nessuna telemetriaNessun programma raccoglie o invia dati sul tuo uso. Nessun account obbligatorio.
  • Aggiornamenti automaticiLe correzioni di sicurezza si installano da sole fino ad aprile 2029, comprese quelle di Firefox.
  • Secure BootSi avvia con Secure Boot attivo, e anche sui PC con BIOS tradizionale.
  • Nessuna porta apertaSul desktop nessun servizio ascolta in rete. Sui server solo SSH con chiave.
  • AppArmorI profili di sicurezza sono attivi. Le app Trota non chiedono mai i permessi di amministratore.
  • Applicazioni isolateLe app di Flathub girano separate dal sistema e si aggiornano una volta al giorno.

Vai ai file del rilascio Guida all'installazione

  1. Verifica il file

    Ogni file ha accanto il suo checksum SHA-256.

    $ sha256sum -c trota-os-1.0-amd64.iso.sha256 trota-os-1.0-amd64.iso: OK

  2. Prepara la chiavetta

    Usa balenaEtcher o GNOME Disks. Dal terminale, il comando cancella il disco indicato.

    $ sudo dd if=trota-os-1.0-amd64.iso \ of=/dev/sdX bs=4M conv=fsync

  3. Avvia e prova

    Avvia il computer dalla chiavetta: Trota OS parte senza installare nulla. L'icona sul desktop avvia l'installazione.

Per il desktop servono un processore x86 a 64 bit, 4 GB di RAM (meglio 8) e 25 GB di disco. Server, cloud e kiosk partono da 2 GB di RAM e 4 GB di disco.

Domande

Quanto costa?

Niente. Le parti originali di Trota OS sono sotto licenza GPL-3.0, grafica e documentazione sotto CC BY-SA 4.0.

I programmi per Linux funzionano?

Sì. Trota OS usa i pacchetti di Ubuntu 24.04 LTS, quindi i pacchetti .deb, i PPA e i repository pensati per quella versione funzionano anche qui. In più ci sono le app Flatpak di Flathub.

Fino a quando riceve aggiornamenti?

Gli aggiornamenti di sicurezza arrivano fino ad aprile 2029 e si installano da soli. Le nuove versioni di Trota OS escono come nuove immagini.

Perché non ci sono gli snap?

Per tenere il sistema leggero: Firefox è il pacchetto ufficiale di Mozilla e le altre applicazioni arrivano da Flathub. Chi vuole gli snap può riattivarli.

Serve un account o una connessione?

No. La rete serve solo per gli aggiornamenti e per installare nuove applicazioni.
